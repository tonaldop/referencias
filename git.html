🔀 Git — Referência Completa

Guia prático com comandos essenciais e avançados

⚙️ Configuração Inicial

Comando O que faz
git config --global user.name "Nome" Define o nome do usuário
git config --global user.email "email" Define o e-mail do usuário
git config --global core.editor "code --wait" Define o editor padrão (VS Code)
git config --global init.defaultBranch main Define main como branch padrão
git config --global alias.st status Cria atalhos personalizados
git config --list Lista todas as configurações
💡 Dica: Use --global para o usuário, --local para o projeto atual.

📦 Criar, Clonar e Remover

Comando O que faz
git init Cria um novo repositório local
git init --bare Cria repositório sem working tree (servidor)
git clone <url> Clona um repositório remoto
git clone --depth 1 <url> Clona apenas o último commit (shallow)
git clone -b <branch> <url> Clona um branch específico

📸 Estado e Histórico

Comando O que faz
git status Mostra arquivos modificados/novos
git status -s Status resumido
git log Histórico completo de commits
git log --oneline Histórico resumido
git log --graph --oneline --all Gráfico de branches
git log -p <arquivo> Histórico de um arquivo com diffs
git log --author="Nome" Filtra por autor
git log --since="2 weeks ago" Filtra por data
git diff Diferenças não adicionadas
git diff --staged Diferenças já em stage
git diff branch1..branch2 Diferenças entre branches
git show <hash> Detalhes de um commit
git blame <arquivo> Quem alterou cada linha
git shortlog -sn Quantos commits por autor

💾 Salvando Alterações

Comando O que faz
git add <arquivo> Adiciona um arquivo ao stage
git add . Adiciona todas as alterações
git add -p Adiciona por partes (interativo)
git commit -m "mensagem" Cria um commit
git commit -am "msg" Add + commit em arquivos rastreados
git commit --amend Edita o último commit
git commit --amend --no-edit Adiciona ao último commit sem editar msg

📝 Padrões de Mensagens de Commit

Tipo Quando usar
feat: Nova funcionalidade
fix: Correção de bug
docs: Documentação
style: Formatação (sem mudança de lógica)
refactor: Refatoração (sem nova feature ou fix)
test: Adição/correção de testes
chore: Tarefas (build, deps, config)
perf: Melhoria de performance
ci: Integração contínua
revert: Reverter commit anterior

Exemplos práticos

feat(auth): adiciona login com Google
fix(api): corrige erro 500 ao listar usuários
docs(readme): atualiza instruções de instalação
refactor(utils): simplifica função de formatação
chore(deps): atualiza dependências do projeto
💡 Formato: tipo(escopo): descrição curta — escopo é opcional.

🌿 Branches

Comando O que faz
git branch Lista branches locais
git branch -a Lista locais e remotos
git branch -v Lista com último commit
git branch <nome> Cria um novo branch
git branch -m <novo> Renomeia o branch atual
git checkout <nome> Troca para o branch
git checkout -b <nome> Cria e troca
git switch <nome> Troca (comando moderno)
git switch -c <nome> Cria e troca (moderno)
git merge <branch> Mescla na branch atual
git merge --no-ff <branch> Merge sem fast-forward
git branch -d <nome> Deleta branch (seguro)
git branch -D <nome> Força exclusão

🔀 Rebase e Cherry-pick

Comando O que faz
git rebase <branch> Reaplica commits sobre outra branch
git rebase -i HEAD~3 Rebase interativo dos últimos 3 commits
git rebase --continue Continua após resolver conflito
git rebase --abort Cancela o rebase
git cherry-pick <hash> Aplica um commit específico
git cherry-pick <h1>..<h2> Aplica um intervalo de commits
⚠️ Atenção: Nunca faça rebase em branches já compartilhados publicamente.

☁️ Repositórios Remotos

Comando O que faz
git remote -v Lista remotos
git remote add origin <url> Adiciona um remoto
git remote set-url origin <url> Altera a URL do remoto
git remote remove origin Remove o remoto
git push origin <branch> Envia commits
git push -u origin <branch> Envia e define upstream
git push origin --delete <branch> Deleta branch remoto
git push --force-with-lease Force seguro (recomendado)
git push --force ⚠️ Force bruto (cuidado!)
git pull Fetch + merge
git pull --rebase Fetch + rebase
git fetch Baixa sem mesclar
git fetch --prune Remove refs de branches deletados

↩️ Desfazendo Coisas

Comando O que faz
git restore <arquivo> Descarta alterações não commitadas
git restore --staged <arq> Remove do stage (mantém alterações)
git restore --source=HEAD~2 <arq> Restaura arquivo de um commit antigo
git reset --soft HEAD~1 Desfaz commit mantendo stage
git reset --mixed HEAD~1 Desfaz commit (padrão)
git reset --hard HEAD~1 ⚠️ Desfaz commit e alterações
git revert <hash> Cria commit que desfaz outro
git reflog Histórico de tudo (recuperação)
💡 Recuperação: Usou reset --hard por engano? Use git reflog para achar o hash e recuperar.

📥 Guardando Temporariamente (Stash)

Comando O que faz
git stash Guarda alterações temporariamente
git stash -u Inclui arquivos não rastreados
git stash save "msg" Guarda com descrição
git stash list Lista stashes
git stash pop Recupera e remove o último
git stash apply stash@{2} Aplica um stash específico
git stash drop stash@{0} Remove um stash
git stash clear Remove todos os stashes

🏷️ Tags

Comando O que faz
git tag Lista tags
git tag v1.0.0 Cria tag leve
git tag -a v1.0 -m "msg" Tag anotada
git tag -d v1.0 Deleta tag local
git push origin v1.0 Envia tag específica
git push --tags Envia todas as tags
git push origin --delete v1.0 Deleta tag remota

🔍 Busca e Inspeção

Comando O que faz
git grep "texto" Busca em arquivos rastreados
git log -S "função" Commits que adicionaram/removeram texto
git log --grep="bug" Busca em mensagens de commit
git bisect start Busca binária de bug
git bisect good/bad Marca commits na busca
git bisect reset Finaliza a busca
git fsck Verifica integridade do repositório

🧹 Limpeza e Manutenção

Comando O que faz
git clean -n Simula limpeza (dry-run)
git clean -f Remove arquivos não rastreados
git clean -fd ⚠️ Remove arquivos e diretórios
git gc Garbage collector (otimiza)
git prune Remove objetos inalcançáveis
git rm <arquivo> Remove arquivo do repositório
git rm --cached <arquivo> Remove do Git (mantém no disco)
git mv <orig> <dest> Move/renomeia arquivo

🚑 Situações de Emergência

Commitei no branch errado

git reset HEAD~1                    # desfaz o commit
git stash                           # guarda alterações
git switch branch-correto           # vai para o branch certo
git stash pop                       # aplica alterações
git add . && git commit -m "msg"    # commita no lugar certo

Preciso desfazer um push

git revert <hash>                   # cria commit de reversão
git push origin main                # envia (seguro para branches públicos)

Conflito no merge

# 1. Edite os arquivos com conflito (<<<<<<< ======= >>>>>>>)
git add <arquivos-resolvidos>       # marca como resolvido
git commit                          # finaliza o merge
# OU para cancelar:
git merge --abort

Recuperar commit "perdido"

git reflog                          # encontra o hash
git checkout <hash>                 # testa
git branch recuperado <hash>        # cria branch apontando para ele

🧭 Fluxo de Trabalho Típico

# 1. Clonar o projeto
git clone https://github.com/user/repo.git
cd repo

# 2. Criar branch para a feature
git switch -c feat/nova-funcionalidade

# 3. Trabalhar e commitar
git add .
git commit -m "feat: adiciona nova funcionalidade"

# 4. Manter atualizado com o remoto
git fetch origin
git rebase origin/main

# 5. Enviar para o remoto
git push -u origin feat/nova-funcionalidade

# 6. Abrir Pull Request no GitHub/GitLab
