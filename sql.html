🔌 Conexão e Servidor

Comando O que faz
mysql -u root -p Conecta como root (pede senha)
mysql -u user -p -h host Conecta a um host específico
mysql -u user -p db_name Conecta já usando um banco
mysql -u user -p < arquivo.sql Executa um script SQL
mysqldump -u user -p db > backup.sql Faz backup de um banco
mysql -u user -p db < backup.sql Restaura backup
EXIT; ou QUIT; Sai do cliente MySQL

🆕 CREATE TABLE

CREATE TABLE usuarios (
  id         INT AUTO_INCREMENT PRIMARY KEY,
  nome       VARCHAR(100)  NOT NULL,
  email      VARCHAR(150)  UNIQUE NOT NULL,
  idade      INT,
  ativo      BOOLEAN       DEFAULT TRUE,
  criado_em  TIMESTAMP     DEFAULT CURRENT_TIMESTAMP
);

Tipos de dados mais usados

Tipo Uso
INT / BIGINT Números inteiros
DECIMAL(10,2) Valores monetários (exatos)
FLOAT / DOUBLE Números com casas decimais
VARCHAR(n) Texto variável até n caracteres
TEXT Textos longos
DATE Data (YYYY-MM-DD)
DATETIME / TIMESTAMP Data e hora
BOOLEAN Verdadeiro/falso (TINYINT(1))
ENUM('a','b') Lista fixa de valores
JSON Documento JSON

➕ INSERT (Inserir dados)

Comando O que faz
INSERT INTO t (c1,c2) VALUES (v1,v2); Insere uma linha
INSERT INTO t VALUES (v1,v2); Insere todos os campos na ordem
INSERT INTO t (c1) VALUES (v1),(v2),(v3); Múltiplas linhas de uma vez
INSERT INTO t SELECT ...; Insere a partir de outra consulta
INSERT IGNORE INTO t ...; Ignora erros de duplicidade
INSERT ... ON DUPLICATE KEY UPDATE c=v; Insere ou atualiza se existir

🔍 SELECT — Consultas

SELECT coluna1, coluna2
FROM tabela
WHERE condição
GROUP BY coluna
HAVING condição_do_grupo
ORDER BY coluna ASC|DESC
LIMIT 10 OFFSET 0;

Ordem de execução das cláusulas

FROM  →  WHERE  →  GROUP BY  →  HAVING  →  SELECT  →  ORDER BY  →  LIMIT
Exemplo O que faz
SELECT * FROM usuarios; Todas as colunas e linhas
SELECT nome, email FROM usuarios; Apenas algumas colunas
SELECT * FROM usuarios LIMIT 5; Primeiras 5 linhas
SELECT * FROM usuarios LIMIT 5 OFFSET 10; Paginação (pula 10, pega 5)
SELECT DISTINCT cidade FROM u; Valores únicos
SELECT * FROM u ORDER BY nome; Ordena crescente
SELECT * FROM u ORDER BY idade DESC; Ordena decrescente
SELECT * FROM u ORDER BY nome ASC, idade DESC; Ordenação múltipla

🎯 WHERE — Filtros

Operador / Exemplo O que faz
= , != , <> , < , > , <= , >= Comparações básicas
WHERE idade BETWEEN 18 AND 30 Intervalo (inclusive)
WHERE nome IN ('Ana','Bia') Está na lista
WHERE nome NOT IN ('Ana') Não está na lista
WHERE nome LIKE 'A%' Começa com "A" (% = qualquer)
WHERE nome LIKE '%silva%' Contém "silva"
WHERE nome LIKE '_na' 1 caractere qualquer + "na"
WHERE email IS NULL Campo nulo
WHERE email IS NOT NULL Campo não nulo
WHERE ativo = 1 AND idade >= 18 E lógico
WHERE cidade = 'SP' OR cidade = 'RJ' OU lógico
WHERE NOT ativo Negação

✏️ UPDATE e DELETE

Comando O que faz
UPDATE u SET nome='X' WHERE id=1; Atualiza uma linha
UPDATE u SET ativo=0 WHERE idade < 18; Atualiza várias linhas
UPDATE u SET a=1, b=2 WHERE id=1; Atualiza várias colunas
DELETE FROM u WHERE id=1; Apaga uma linha
DELETE FROM u WHERE idade < 18; Apaga várias linhas
DELETE FROM u; ⚠️ Apaga TODAS as linhas
⚠️ Cuidado: Sempre teste o WHERE com um SELECT antes de rodar UPDATE ou DELETE. E use transações (BEGIN / ROLLBACK) quando possível.

🔗 JOINs — Juntando Tabelas

Tipo O que retorna
INNER JOIN Apenas linhas que casam nas duas tabelas
LEFT JOIN Todas da esquerda + casadas da direita (NULL se não houver)
RIGHT JOIN Todas da direita + casadas da esquerda
CROSS JOIN Produto cartesiano (todas × todas)
SELF JOIN Junta a tabela com ela mesma (alias) 
SELECT u.nome, p.titulo
FROM usuarios u
INNER JOIN pedidos p ON p.usuario_id = u.id
WHERE u.ativo = 1
ORDER BY u.nome;
💡 Dica: sempre use alias (u, p) para deixar a query mais curta e legível.

📊 Funções de Agregação

Função O que faz
COUNT(*) Conta linhas
COUNT(DISTINCT col) Conta valores únicos
SUM(col) Soma valores
AVG(col) Média
MIN(col) / MAX(col) Mínimo / máximo
GROUP_CONCAT(col) Junta valores em uma string 
SELECT cidade, COUNT(*) AS total, AVG(idade) AS media
FROM usuarios
GROUP BY cidade
HAVING total > 5
ORDER BY total DESC;
💡 WHERE vs HAVING: WHERE filtra antes do agrupamento; HAVING filtra depois (pode usar funções de agregação).

🔀 Condicionais e NULL

Função O que faz
IF(cond, a, b) Retorna a ou b
IFNULL(x, alt) Se x for NULL, retorna alt
NULLIF(a, b) NULL se a = b
COALESCE(a, b, c) Primeiro valor não nulo
CASE WHEN ... THEN ... ELSE ... END Condicional tipo "switch" 
SELECT nome,
       CASE
         WHEN idade < 18 THEN 'Menor'
         WHEN idade < 60 THEN 'Adulto'
         ELSE 'Idoso'
       END AS faixa
FROM usuarios;

🔄 Transações

START TRANSACTION;

UPDATE contas SET saldo = saldo - 100 WHERE id = 1;
UPDATE contas SET saldo = saldo + 100 WHERE id = 2;

-- Se tudo ok:
COMMIT;

-- Se algo deu errado:
ROLLBACK;
💡 ACID: Atomicidade, Consistência, Isolamento, Durabilidade. Use transações quando múltiplas operações precisam ser tudo ou nada.

⚡ Boas Práticas e Performance

Prática Por quê
Use EXPLAIN antes de otimizar Mostra plano de execução real
Crie índices em colunas de WHERE / JOIN Acelera consultas drasticamente
Evite SELECT * em produção Tráfego desnecessário
Prefira EXISTS a IN em subqueries grandes Melhor performance
Use LIMIT em testes Evita travar com milhares de linhas
Nunca armazene senhas em texto puro Use hash (bcrypt, argon2)
Backup antes de rodar scripts grandes mysqldump salva vidas

🚑 Situações Comuns

Encontrar duplicatas

SELECT email, COUNT(*) AS qtd
FROM usuarios
GROUP BY email
HAVING qtd > 1;

Segunda maior idade

SELECT MAX(idade) FROM usuarios
WHERE idade < (SELECT MAX(idade) FROM usuarios);

Top N por grupo

SELECT *
FROM (
  SELECT *, ROW_NUMBER() OVER (PARTITION BY cidade ORDER BY idade DESC) AS rn
  FROM usuarios
) t
WHERE rn <= 3;

Pagar / restaurar um banco

mysqldump -u root -p meu_banco > backup.sql
mysql -u root -p meu_banco < backup.sql

🧭 Fluxo de Trabalho Típico

-- 1. Criar banco e usar
CREATE DATABASE loja CHARACTER SET utf8mb4;
USE loja;

-- 2. Criar tabela
CREATE TABLE produtos (
  id     INT AUTO_INCREMENT PRIMARY KEY,
  nome   VARCHAR(100) NOT NULL,
  preco  DECIMAL(10,2) NOT NULL
);

-- 3. Inserir dados
INSERT INTO produtos (nome, preco) VALUES
  ('Teclado', 150.00),
  ('Mouse',   80.00);

-- 4. Consultar
SELECT * FROM produtos WHERE preco > 100 ORDER BY preco DESC;
