💾 Tipos Primitivos

Tipo Descrição Exemplos

➕ Operadores Aritméticos

Operador Nome Exemplo Resultado
+ Adição 5 + 3 8
- Subtração 5 - 3 2
* Multiplicação 5 * 3 15
/ Divisão 10 / 3 3.33...
// ou div Divisão inteira 10 // 3 3
% Módulo (resto) 10 % 3 1
** ou ^ Potência 2 ** 3 8
⚠️ Cuidado: em C/Java/JS, / entre dois inteiros faz divisão inteira (ex: 5/2 = 2). Em Python 3, 5/2 = 2.5.

Precedência (ordem de execução)

1º  ( )          → parênteses
2º  ** / ^       → potência
3º  * / // %     → multiplicação, divisão, módulo
4º  + -          → adição e subtração

Exemplo:  2 + 3 * 4 = 2 + 12 = 14
           (2 + 3) * 4 = 5 * 4 = 20

🔍 Operadores Relacionais (Comparação)

Operador Significado Exemplo Resultado
== Igual a 5 == 5 true
!= Diferente de 5 != 3 true
> Maior que 5 > 3 true
< Menor que 5 < 3 false
>= Maior ou igual 5 >= 5 true
<= Menor ou igual 5 <= 3 false
⚠️ Não confunda: = é atribuição (guarda valor). == é comparação (testa igualdade).

📚 Array / Vetor

// Criar
numeros = [10, 20, 30, 40, 50]
matriz  = [[1, 2], [3, 4]]

// Acessar (índice começa em 0)
numeros[0]     → 10
numeros[2]     → 30
numeros[-1]    → 50 (último, em Python)

// Modificar
numeros[1] = 25

// Tamanho
len(numeros)   → 5

// Percorrer
for n in numeros:
    print(n)
💡 Índice começa em 0 na maioria das linguagens (C, Java, Python, JS). Algumas como Lua e R começam em 1.

🥞 Pilha (Stack) — LIFO

Último a entrar, primeiro a sair
Exemplo: histórico do navegador, Ctrl+Z

      ┌─────┐
      │  C  │  ← topo (push/pop)
      ├─────┤
      │  B  │
      ├─────┤
      │  A  │
      └─────┘
      base

push(x)  → empilha
pop()    → desempilha (remove o do topo)
peek()   → olha o topo sem remover
isEmpty()→ está vazia?

Uso em Python (list)

pilha = []
pilha.append("A")    # push
pilha.append("B")
pilha.append("C")
topo = pilha.pop()   # → "C"

🚶 Fila (Queue) — FIFO

Primeiro a entrar, primeiro a sair
Exemplo: fila de impressão, atendimento

  entrada →  [ A | B | C | D ]  → saída
              ↑             ↑
             fim          início

enqueue(x) → entra no fim
dequeue()  → sai do início
front()    → olha o primeiro
isEmpty()  → está vazia?

Uso em Python (deque)

from collections import deque

fila = deque()
fila.append("A")       # entra no fim
fila.append("B")
primeiro = fila.popleft()  # → "A"

🧠 Lógica de Programação — Estruturas

Condicional (if / else)

SE condição ENTÃO
    faça isso
SENÃO SE outra_condição ENTÃO
    faça aquilo
SENÃO
    faça outra coisa
FIM

Laço (while)

ENQUANTO condição FAÇA
    instruções
FIM ENQUANTO

Exemplo: contar de 1 a 5
i = 1
ENQUANTO i <= 5:
    imprimir(i)
    i = i + 1

Laço (for)

PARA cada item EM coleção FAÇA
    instruções
FIM PARA

Exemplo:
PARA i DE 1 ATÉ 5:
    imprimir(i)

🔁 Controle de Laço

Comando O que faz
break Interrompe o laço imediatamente
continue Pula para a próxima iteração
return Sai da função (e do laço)
pass / nop Não faz nada (placeholder) 
for i in range(10):
    if i == 5:
        break        # para quando i = 5
    if i % 2 == 0:
        continue     # pula pares
    print(i)         # imprime 1, 3

maior = lista[0]

Fatorial

fat = 1
for i in range(2, n+1):
    fat *= i

# Recursivo
def fatorial(n):
    if n <= 1:
        return 1
    return n * fatorial(n - 1)

Fibonacci

a, b = 0, 1
for _ in range(n):
    print(a)
    a, b = b, a + b

É primo?

def eh_primo(n):
    if n < 2:
        return False
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            return False
    return True

Busca linear

def busca(lista, alvo):
    for i, x in enumerate(lista):
        if x == alvo:
            return i
    return -1

Busca binária (lista ordenada)

def busca_binaria(lista, alvo):
    esq, dir = 0, len(lista) - 1
    while esq <= dir:
        meio = (esq + dir) // 2
        if lista[meio] == alvo:
            return meio
        elif lista[meio] < alvo:
            esq = meio + 1
        else:
            dir = meio - 1
    return -1

Bubble Sort

def bubble_sort(lista):
    n = len(lista)
    for i in range(n):
        for j in range(n - i - 1):
            if lista[j] > lista[j+1]:
                lista[j], lista[j+1] = lista[j+1], lista[j]
    return lista

📈 Complexidade (Big-O) — Noções

Notação Nome Exemplo
O(1) Constante Acessar lista[5]
O(log n) Logarítmica Busca binária
O(n) Linear Busca em lista
O(n log n) Quase linear Merge sort, Quick sort
O(n²) Quadrática Bubble sort
O(2ⁿ) Exponencial Fibonacci recursivo ingênuo
💡 Big-O mede como o tempo cresce quando a entrada aumenta. Prefira sempre complexidades menores.

🚑 Erros Comuns de Iniciantes

Erro Como evitar
Confundir = com == = atribui, == compara
Esquecer de incrementar no while Loop infinito! Sempre modifique a condição
Divisão por zero Verifique antes: if y != 0
Índice fora do intervalo Lista de tamanho n tem índices 0 a n-1
Comparar float com == Use tolerância: abs(a - b) < 0.0001
