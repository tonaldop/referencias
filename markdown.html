📝 Markdown — Referência Rápida

Comandos básicos de formatação

🔤 Ênfase e Texto

O que você escreve Como aparece
*itálico* ou _itálico_ itálico
**negrito** ou __negrito__ negrito
***negrito e itálico*** negrito e itálico
~~tachado~~ tachado
`código inline` código inline

📌 Títulos

O que você escreve Resultado
# Título 1 Maior título (H1)
## Título 2 Subtítulo (H2)
### Título 3 Subtítulo (H3)
#### até ###### Níveis H4 a H6

📋 Listas

O que você escreve Resultado
- Item
- Item		 Lista com marcadores
* Item ou + Item Também lista com marcadores
1. Item
2. Item		 Lista numerada
- Subitem Subitem (indentado com 2 espaços)
- [ ] Tarefa ☐ Tarefa (não concluída)
- [x] Tarefa ☑ Tarefa (concluída)

🔗 Links e Imagens

O que você escreve Resultado
[Texto do link](https://site.com) Texto do link
[Texto](url "Título") Link com tooltip
![Alt](imagem.jpg) Imagem
<https://site.com> URL automática

💻 Blocos de Código

O que você escreve Resultado
``` (3 crases) Bloco de código
```python Bloco com destaque de sintaxe
Indentar 4 espaços Também cria bloco de código

📊 Tabelas

O que você escreve Resultado
| Col1 | Col2 |
|------|------|
| A | B | 		Tabela com 2 colunas e 1 linha
|:---| Alinhado à esquerda
|:---:| Centralizado
|---:| Alinhado à direita

📎 Citações e Divisores

O que você escreve Resultado
> Texto citado Bloco de citação
>> Citação aninhada Citação dentro de citação
--- ou *** Linha divisória horizontal
<br> Quebra de linha (HTML)

⌨️ Escapes (Caracteres Especiais)

O que você escreve Resultado
\*texto\* *texto* (literal, sem formatação)
\_texto\_ _texto_
\# título # título (sem virar título)
\`código\` `código` (literal)
